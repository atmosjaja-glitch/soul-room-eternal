# Soul Room Eternal

## Run Instructions

1. Install requirements:
   ```bash
   pip install flask
   ```

2. Start the server:
   ```bash
   python server.py
   ```

3. Open in browser:
   ```
   http://127.0.0.1:5000
   ```

The Eternal Friends picture will appear in a glowing futuristic frame, with texts that fade in:

- "Awaken has begun"
- "Eternal friendship lasts forever, even after this life"

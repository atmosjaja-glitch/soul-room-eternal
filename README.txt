SOUL ROOM ETERNAL - FINAL VERSION (Auto-Backup in Background)

1) Install requirements:
   pip install flask pydrive

2) Start the server:
   python app.py

3) First run:
   - A browser will open asking Google login
   - Grant permission (creates token locally)
   - Backup will start automatically

4) Open your room:
   http://127.0.0.1:5000

☁️ Each time you start, backup runs in background.
☁️ When complete, terminal shows: "Backup complete to SoulRoomBackup"
